## 🧰 Projects

Tools I've built from scratch to understand how systems work under the hood.

| Project | What it does | Stack |
|---------|--------------|-------|
| **[procmon](https://github.com/72samuu/procmon)** | Linux system & process monitor that reads the kernel's `/proc` filesystem directly — the same source `top` and `htop` use. Reports CPU, memory and per-process load with zero third-party libraries; every value is parsed by hand and documented. Tested with 17 unit tests against fake `/proc` trees. | Python, Linux `/proc` |
