## 🧰 Projects

| Project | What it does | Stack |
|---------|--------------|-------|
| **[procmon](https://github.com/72samuu/procmon)** | Linux system & process monitor that reads the kernel's `/proc` filesystem directly — the same source `top` and `htop` use. Tested with 17 unit tests against fake `/proc` trees. | Python, Linux `/proc` |
